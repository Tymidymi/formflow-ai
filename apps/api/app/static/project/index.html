Gotowy do przeglądu i korekty
PROCES

Cyfryzacja w trzech krokach.

Bez ręcznego przepisywania każdego pytania i bez utraty kontroli nad ostateczną strukturą formularza.

01

Prześlij dokument

PDF, skan, Word lub arkusz. Silnik odczytuje strony, tekst, układ i obszary odpowiedzi.

02

Sprawdź i popraw

Porównaj oryginał z interaktywnym formularzem. Edytuj pytania, sekcje, opcje i reguły walidacji.

03

Wyeksportuj JSON COI

Walidacja struktury i eksport definicji formularza gotowej do dalszej integracji.

ARCHITEKTURA

Oparte na otwartych komponentach.

Oddzielne warstwy ekstrakcji, interpretacji i walidacji — z jednoznacznym podziałem odpowiedzialności.

Dokumenty i OCR

LibreOffice · Docling Slim · Tesseract · PDFium

Interpretacja AI

Open-weight Qwen3-VL · multimodalna analiza stron

API i eksport

Python · FastAPI · schemat JSON COI · Docker

Weryfikacja

React · JSON Forms · edytor sekcji i pól
